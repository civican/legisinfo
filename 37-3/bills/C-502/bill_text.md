| The purpose of this enactment is to amend the Criminal Code to eliminate artistic merit and public good as defences to a charge relating to child pornography. | Le texte modifie le Code criminel afin de supprimer le moyen de défense fondé sur la valeur artistique et celui fondé sur le bien public dans le cas d'une infraction de pornographie juvénile. |
