Bill C-57 PublicationID : 2329564 Table of ContentsSummaryBILL C-57

|  | SUMMARY |  |
| --- | --- | --- |
|  | This enactment removes the prohibition against Bell Canada and any person controlled by Bell Canada from directly or indirectly holding a broadcasting licence or operating a broadcasting undertaking. |  |
|  | EXPLANATORY NOTES |  |
|  | Bell Canada Act |  |
|  | Clause 1: Section 7 reads as follows: |  |
|  | 7. Neither the Company nor any person controlled by the Company shall directly or indirectly hold a licence issued under the Broadcasting Act or carry on a broadcasting undertaking within the meaning of that Act. |  |

|  | 2nd Session, 35th Parliament, 45 Elizabeth II, 1996-97 |
| --- | --- |

The House of Commons of Canada # BILL C-57 An Act to amend the Bell Canada Act 1987, c. 19; 1991, c. 11; 1992, c. 1; 1993, c. 38 Her Majesty, by and with the advice and consent of the Senate and House of Commons of Canada, enacts as follows: 1991, c. 11, s. 72 **1.** Section 7 of the *Bell Canada Act* is repealed.
